# 00 — Constitution Program Plan

Status: ACTIVE

## Mission

Establish a contract-driven engineering system for OpenCode-Hi in which component semantics are canonical, host projections are generated or mechanically validated, runtime ownership is explicit, and behavioral acceptance proves representative execution.

## Mandatory sequence

1. Preserve and verify the pre-existing working tree.
2. Inventory every supplied/reference source project.
3. Study source architecture, not only README claims.
4. Map current OpenCode-Hi runtime owners and executor paths.
5. Inventory recurring failure patterns and duplicate truth.
6. Define domain ontology.
7. Define the component metamodel.
8. Define component contracts and templates.
9. Define machine schemas and canonical catalogs.
10. Define projection/generator boundaries.
11. Define validators and architectural lint.
12. Define behavioral acceptance.
13. Define host projection/capability contracts.
14. Define migration order and current-only replacement rules.
15. Maintain a source adoption/rejection register.
16. Write the consolidated engineering constitution.
17. Implement in bounded migrations, validating and committing every coherent mutation cycle.

## Non-negotiable gates

- SOURCE_GROUNDED: no borrowed architecture without source evidence.
- OWNER_UNIQUE: one canonical owner for each semantic decision.
- EXECUTOR_REAL: operational claims require a real runtime/host consumer.
- PROJECTION_PARITY: prompt/config/docs projections must match canonical contracts.
- BEHAVIOR_PROVEN: representative runtime behavior must be tested.
- CURRENT_ONLY: do not preserve obsolete duplicate semantics as compatibility baggage.
- WORKTREE_SAFE: pre-existing user work is never discarded.
- LOCAL_COMMIT: every coherent mutation-bearing cycle ends in a verified local commit.
