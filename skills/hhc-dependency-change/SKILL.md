# Bağımlılık Değişikliği

Önce değişikliğin gerçekten gerekli olduğunu doğrula. Doğrudan/transitif etkiyi, sürüm aralığını, lockfile farkını, runtime/build uyumluluğunu ve bilinen güvenlik etkisini resmi/birincil kaynakla gerektiği kadar kontrol et. Sırf yeni sürüm var diye upgrade yapma; install/publish veya network side-effect kullanıcı politikasını aşmasın.
