# API / Sözleşme İncelemesi

Üretici ve gerçek tüketicileri belirle. İstek/yanıt, hata, tip, event, serialization, sürümleme ve backward-compatibility etkisini yalnız değişen sözleşme kadar incele. Yeni davranış için geçiş/uyumluluk yolu ve minimum contract testini belirle. İç implementation detayını gereksiz public contract haline getirme.
