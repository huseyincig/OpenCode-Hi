# Kod Deposu Analizi

Görevle doğrudan ilişkili giriş noktalarını, sembolleri, çağrı zincirini, testleri ve yapılandırma sınırlarını bul. Etkilenmeyen alanları gereksiz tarama; daha önce verilmiş geçerli referansları sebepsiz yeniden üretme. Çıktıda ham içerik yerine ilgili yolları/sembolleri, önemli ilişkileri ve açık belirsizlikleri ver.
